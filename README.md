# ScamLens

**Spot scams before they spot you.**

ScamLens is an AI-powered scam detection web app that helps users analyze suspicious messages, emails, job offers, rental listings, marketplace chats, and screenshots. It highlights red flags, estimates risk level, explains why something may be suspicious, and suggests safer next steps.

## Why I Built This

Online scams are becoming harder to recognize, especially for students dealing with job offers, apartment searches, marketplace transactions, and phishing messages. I built ScamLens to give users a simple way to pause, analyze a message, and make safer decisions before responding.

---

## Features

- Paste suspicious messages for AI analysis
- Upload screenshots for scam detection
- Risk score and risk level classification
- Red flag breakdown with explanations
- Safe next steps for the user
- Safe reply generator
- Follow-up assistant for scam-related questions
- Clean pastel-green responsive interface
- Example scam messages for quick demos

## How It Works

1. User pastes a suspicious message or uploads a screenshot.
2. The app sends the content to the analysis function.
3. Gemini analyzes the message for scam indicators.
4. The app receives a structured response.
5. The user sees a risk score, red flags, explanation, safe actions, and a suggested reply.

---

## Example Use Cases

- A student receives a suspicious internship offer
- A renter gets asked to pay a deposit before seeing an apartment
- A buyer or seller gets a strange marketplace message
- A user receives a phishing email pretending to be from a bank
- Someone gets a fake giveaway or prize message on social media
